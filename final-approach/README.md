# Final Approach — browser prototype 0.1

Open `index.html` in a desktop browser or host it on any static web host (GitHub Pages, Netlify, Cloudflare Pages) to play on an iPhone in Safari.

## Gameplay
- Drag from aircraft to draw flight paths.
- Yellow jets and cyan prop planes land on the runway.
- Pink helicopters land on the helipad.
- Avoid collisions; traffic increases with your score.

## Notes
This is a proof of concept, not yet an App Store-ready build. Next iterations: route endpoint snapping, approach direction/heading validation, more maps, sound, persistent high scores, accessibility, and production art.
