# Final Approach 0.3

Upload `index.html` to the root of your GitHub Pages repository, replacing the previous version.

New: multiple directional runways, three maps unlocked at 0/20/60 cumulative landings, safety grades, approach quality points, near misses, persistent progress.

Draw a path by pressing an aircraft and dragging. For fixed-wing landings, line up on the dotted final approach corridor and cross the runway threshold in the indicated direction. Helicopters land on the H.

This is a prototype: approach scoring is arcade-oriented, and runway crossing checks are simplified.
